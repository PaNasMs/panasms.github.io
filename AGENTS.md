# Website delivery

- Use feature branches and pull requests for this GitHub Pages repository.
- Automatic CodeRabbit and Sourcery reviews are disabled for this repository.
  Do not request or wait for automated reviews unless the owner explicitly asks.
- Require successful site build, link checks and applicable tests before merging.
  Verify GitHub Pages publication after merging.
- This exception applies only to `PaNasMs/panasms.github.io`; other PaNasMs
  repositories retain their automatic-review requirements.
